## 核心特性
- **纯前端本地运行**：简历内容与证件照仅保存在本地浏览器，绝不上传服务器。
- **出版级矢量 A4 PDF 导出**：文字可选中复制，兼容各大企业网申 ATS 系统，无任何水印。
- **5 套精选中文模板**：极简大厂风、经典商务风、现代双栏风、学术科研风、清新应届风。
- **开箱即用**：内置 3 套高质量中文范例、实时 A4 分页参考线、`**加粗**` 高亮语法与 JSON 备份恢复。
